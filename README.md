## Basic Workflow of the Todo List

- This app is desgined to help users with tracking their worklist. 
- Completion of tasks along with time countdown makes users to be more focused on the task and having multiple awards and badges give people motivation to work. 
- The Progress graph lets people know how well they have been doing so far. 
- Sharing work with peers lets people share their happiness.


## How to Install

- Be sure Node JS has been download and set to correct path.
- Clone this repository.
git clone https://github.com/SubratBhattarai/ToDo-List
- Enter the Directory
cd ToDo-List
- install required packages
npm install
- Start the application
npm run dev
- Open up a browser and search
http://localhost:5173


## How to Use
1. Type any tasks in the add input.
2. Click Add to add the task in the list.
3. Check the box on the left side once the task has been completed.
4. Use the trash icon to delete any task.
5. Clear All button helps to clean up the list.
6. Once all tasks are completed. Enjoy by sharing the progress with others.
